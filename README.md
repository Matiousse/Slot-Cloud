# Reimei Games

Dépôt du studio **Reimei Games** (黎明, « l'aube »).

```
Reimei Games/
  intro/                     intro animée du studio, partagée par tous les jeux
  slots/
    raijin-overload/         RAIJIN OVERLOAD — slot 5x5 pour Stake Engine (maths + front)
```

Chaque jeu est un projet autonome : `cd "Reimei Games/slots/<jeu>" && npm install && npm run dev`.
Voir le README de chaque jeu pour les maths, le build et le dépôt sur Stake Engine.
